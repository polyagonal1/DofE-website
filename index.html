Hello

This is a website that I have created for my Duke of Edinburgh Award and has one origami model on it and instructions on how to make it.

If you like, you can explore the website using the navigation bar at the top. Currently, it only includes a link to this page and to the catalogue, which you can have a look at if you like. The catalogue includes a table containing all of the origami models that I have included and each cell links to the page with the instructions showing and telling you how to make it. I have also included diagrams hand-made by me. (You would not believe how long it took me to make them.) I did consider using AI to generate them for me but I decided it wouldn't be authentic enough for my standards.

Also, one more thing, you should note that I have not accounted for mobile users of this website very much, so if you're viewing this on mobile, things might look a bit weird compared to a normal website.
