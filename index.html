Hello

This is a website that I have created for my Duke of Edinburgh Award and is going to have origami models on it, and instructions on how to make each one. It doesn't yet have the origami models or how to make them yet, but it's a work in progress.

If you like, you can explore the website using the navigation bar at the top. Currently, it only includes a link to this page and to the catalogue, which you can have a look at if you like. The catalogue includes a table containing all of the origami models that I have included, but most of the cells in the table are placeholders, and there's only one that links to an actual page containing the page for the origami model, and it doesn't have any proper instructions yet. So this website is pretty useless unless you are my Duke of Edinburgh Award Assessor, in which case you can examine the website to assess my skills in website-making.

Also, you should note that I have not accounted for mobile users of this website very much, so if you're viewing this on mobile, things might look a bit weird compared to a normal website.
